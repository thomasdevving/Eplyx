# U13.2C isolated sequence evidence

`lut-acquisition.json` binds two exact-slot raw `getAccountInfo` responses in `raw/` to the provider host, address, length, context slot, response SHA-256, and decoded data SHA-256. The RPC URL stays in `SOLANA_RPC_URL`; credentials are never retained. These receipts equal the U13.1 parent-slot LUT accounts in full.

`feasibility.json` is generated by `cargo run -p eplyx-engine --example u13_2c_sequence`. It binds the U13.2B historical feature/runtime identity, frozen U13.1 graph and block, universal LUT resolutions, five historical executions in one VM, derived intermediate frontier hashes, complete terminal account comparisons, and isolated controls. It is a research feasibility receipt, not an observation or product proof.

Run `node scripts/check-u13-2c-artifacts.cjs` from the repository root for an offline consistency audit. The report and its limitations are in [phase-u13-2c-historical-causal-execution-closure.md](../../phase-u13-2c-historical-causal-execution-closure.md).
