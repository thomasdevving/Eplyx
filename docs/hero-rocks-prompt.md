# Hero orbital rocks

`frontend/public/orbit-rocks.png` was generated with the built-in imagegen tool from the approved Eplyx hero mock-up. It is a transparent square 2×2 atlas: each quadrant contains one stone. CSS selects each quadrant without additional downloads. The existing orbit controls position and depth; the rocks gently turn while their separate labels remain upright. Reduced motion freezes the orbit and stones, and the assets do not depend on WebGL.
