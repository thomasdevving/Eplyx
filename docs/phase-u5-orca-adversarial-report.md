# Phase U5 — Orca Whirlpools adversarial replay gate

**Decision: C — generic transaction-boundary blocker in the observed direct-swap cohort.** No Orca observation was admitted to schema-2 replay. The first direct SwapV2 passes the same-slot pre-screen, but a later transaction in the same slot takes its Whirlpool, both vaults, the first tick array and oracle as writable. End-of-`S` is therefore not its transaction post-state. The other ten observed direct swaps also fail the existing conservative same-slot screen. The remaining 87 sampled signatures could not be classified because the public RPC throttled full-block requests. This result does not establish that all Orca swaps have boundary interference or that Orca is unsupported.

No replay-core, corpus, bundle, CI or adapter code changed in U5. No `ReplayObservationV2`, historical ELF, exact-slot account observations, local execution, fidelity result, `NoSemanticCoverage` result, Orca corpus or Orca bundle exists. These are gated outcomes, not claimed successes. The public RPC also failed the exact-slot account contract; a requested historical program account at slot `448760958` returned context slot `448800601` and was rejected.

## 5. Product-path gate and mutation status

The frozen eligibility rule selects the first successful, one-target legacy/V0 transaction with a complete envelope, proven LUT/dependencies/binaries/runtime, and clean pre **and post** account boundaries. Sample index 32 is the first observed one-target swap but fails the post-boundary rule. The other ten observed one-target swaps also fail the screen. The 87 missing full blocks and 190 per-signature throttles prevent a claim that no suitable swap exists among all 200 signatures. There is **no admitted first replay candidate**.

The failure taxonomy is **`TransactionBoundaryStateRequired`** for the 11 screened direct swaps, with **`HistoricalEvidenceMissing`** for the unclassified 87 and **`DependencyBinaryMissing` / `RuntimeEvidenceMissing`** remaining unresolved for any attempted replay. No `ExecutionMismatch`, `OutcomeMismatch` or `PostStateMismatch` was observed because no local execution occurred. No semantic adapter was created. `NoSemanticCoverage` is a valid later product outcome, but it was **not reached** here. CompleteExecutionV2 was neither invoked nor relaxed.

**Orca-specific replay-core LOC and branches: 0.** A source scan found no Orca/Whirlpool/program-ID branch in the universal core or existing CI, corpus and replay files. U5 added only collector/diagnostic scripts, raw receipts, derived reports and this document. The observed architectural pressure is generic: U4's end-of-slot account observations cannot certify a transaction's post-state when a later same-slot writer exists, nor its pre-state when an earlier writer exists. A future architecture revision should specify proof-carrying transaction-boundary account observations or deterministic reconstruction from a proven earlier boundary and intervening transactions, including full raw bytes and provenance. That is a **generic Solana boundary primitive**, not an Orca-specific branch. Exact-slot archival acquisition also needs a capable provider; the public RPC used here was insufficient.

Only two requested adversarial checks could be grounded in this gated dataset: the named `same_slot_conflict_rejected` assertion in [screen-orca-u5-sample.py](../scripts/screen-orca-u5-sample.py) rejects all 11 real direct swaps, and `idl_fixed_arity_is_not_runtime_arity` is witnessed by six real SwapV2 instructions with two extra accounts. The classifier also asserts signature/block identity, reports unknown discriminators, and the screen refuses missing writable flags as clean evidence. The other 18 proposed replay mutations, including wrong ELF/deployment, modified tick bytes/order, forged LUTs, substituted post-state, premature semantics and hidden raw post-state mismatch, require an admitted historical observation and were **not run**. No compiler-only result is counted as a mutation pass.

The scripts were rerun against retained raw responses: classification and screen outputs remained byte-identical, with local runs of about `0.7` seconds each. Acquisition was measured separately: 200 one-attempt `getTransaction` calls accumulated `12.633` seconds of curl elapsed time, excluding script pauses and block requests. The [measurement](examples/phase-u5-sample/measurement.json) records 13/22 successful full-block attempts, 6/6 accounts-mode screen attempts and approximately 71 MB of raw/derived sample files. Resolution, CAS validation, materialization, loading, execution, fidelity, semantics, record size, bundle size and unique CAS bytes are **not measured or zero as applicable**, because the product pipeline was never entered. No network time is compared against offline CI.

## 6. Semantics and next decision

The semantic gate was not reached. There are no Orca ActionIds, economic subjects, measurement provenance labels, CLMM evaluator, candidate binary, differential result or adapter LOC to report. Token decoding, account deltas, pairing and U1 payoff cannot be measured for an Orca adapter from this phase. The observed interface pressure is specific and factual: six SwapV2 transactions have two remaining accounts; the source makes swap direction and exact-input/output behavior argument-dependent; Token and Token-2022 programs coexist in the first direct swap. Whether ProtocolAdapter V1 is sufficient, awkward or impossible for a correct economic slice remains untested. **Adapter Contract v2 is deferred**; no redesign is justified by an unexecuted slice.

The strongest supported result is that the fourth protocol stressed an unproven generic transaction-boundary assumption while leaving U4's replay core untouched. The phase does **not** meet decision A's required production record, CompleteExecutionV2 match, corpus, bundle, CI and offline replay. The decision is **C**, with a separate **B-style exact-slot acquisition limitation** from the public RPC and unknown status for 87 signatures. The next work should define and validate a generic transaction-boundary evidence contract against a capable archive and repeat a bounded sample; it should not promote a dependency or add an Orca replay branch. Drift is a useful later semantic adversary for internal accounting, margin, funding and PnL, but U5 supplies no basis to start Drift before this replay gate is resolved.

### Claim boundaries

Supported: U4 controls remain exact; the frozen Orca sample and all failed responses are retained; 11 observed direct swaps match the official discriminator index; all 11 fail the current same-slot screen; the first fails specifically on later pool/vault/tick/oracle writers; public RPC current-state responses were rejected as historical evidence; Orca-specific replay-core changes are zero.

Not supported: any Orca production replay match, NoSemanticCoverage product result, historical Whirlpool ELF identity, historical LUT reconstruction, exact account pre/post bytes, token or CLMM economics, all-swap prevalence, all Token-2022 extension behavior, all Orca pools, or universal replay survival for protocol #4.
